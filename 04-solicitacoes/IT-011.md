# IT-011 — Instalação de software

## Tipo

Solicitação de serviço

## Categoria

Software

## Descrição

Usuário solicitou a instalação de um software necessário para execução de suas atividades profissionais.

## Prioridade

Média

## Diagnóstico

Foi analisada a solicitação e verificada a necessidade do software para as atividades do usuário.

## Resolução

O software foi instalado e seu funcionamento foi validado.

## SLA

Tempo de resolução:

**8 horas**

## Status final

Resolvido

## Ferramenta

Jira Service Management
