# Prioridades

## Objetivo

Classificar os tickets de acordo com o impacto e a urgência do problema.

## Critérios

| Prioridade | Impacto | Urgência |
|---|---|---|
| Alta | Alto/Médio | Alta |
| Média | Médio/Baixo | Média |
| Baixa | Baixo | Baixa |

## Incidentes classificados

### Alta

- IT-1 — Usuário sem acesso à internet
- IT-3 — Computador não inicia
- IT-4 — Falha de resolução DNS
- IT-8 — Conta de usuário bloqueada
- IT-10 — Queda de conexão de rede no setor Financeiro

### Média

- IT-2 — Impressora não imprime
- IT-5 — Usuário sem permissão para acessar pasta
- IT-7 — Aplicativo corporativo não abre
- IT-9 — Computador extremamente lento

### Baixa

- IT-6 — Windows Update falhando

## Objetivo operacional

A classificação de prioridade permite organizar o atendimento conforme a criticidade dos incidentes e relacionar cada prioridade aos tempos definidos no SLA.
