# Tipos de Solicitação

## Objetivo

Configurar diferentes tipos de atendimento no Jira Service Management para representar situações comuns de um Service Desk corporativo.

## Incidentes

Utilizados para registrar interrupções ou falhas em serviços de TI.

Exemplos:

- Usuário sem acesso à internet
- Impressora não imprime
- Computador não inicia
- Falha de resolução DNS
- Usuário sem permissão
- Windows Update falhando
- Aplicativo corporativo não abre
- Conta de usuário bloqueada
- Computador lento
- Queda de conexão de rede

## Solicitações

Utilizadas para pedidos realizados pelos usuários.

Exemplos:

- Instalação de software
- Solicitação de novo equipamento
- Solicitação de acesso a sistema
- Criação de conta
- Acesso a pasta compartilhada

## Ferramenta

Jira Service Management
